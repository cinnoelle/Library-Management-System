# Library Management System

A library management program I built in Java that allows users to manage books, magazines, and DVDs. I created this project to practice object-oriented programming, working with different classes, and managing data using ArrayLists.

## Features
- View all items in the library
- Search for items by title
- Check out and return items using their IDs
- Sort items by publication year
- Load library inventory from a text file
- Track whether items are available or checked out

## What I Used
- **Java**
- **Object-Oriented Programming:** Inheritance, polymorphism, abstract classes, and interfaces
- **ArrayLists** to store and manage library items
- **File I/O** to read inventory data from `inventory.txt`
- **Exception Handling** for invalid menu inputs and file errors

## How to Run
1. Download the files and open them in a Java IDE (I used Eclipse).
2. Make sure `inventory.txt` is in the project's working directory.
3. Run `LibraryManagementSystem.java`.
4. Follow the menu options in the console to manage the library.
